# Shape modeling

These guides start with the primitives every design is built from, then go past them. They show how to reshape parts you already have, build parts from curves and outlines, bend and twist space, and raise patterns on a surface. Material attributes travel with the geometry through every operation.

| Guide | Focus |
| --- | --- |
| [Primitive catalog](primitives.md) | The leaf nodes at a glance: basic solids, functions, profile solids, lattices, and imported geometry |
| [Offsets, blends and arrays](offsets-blends-arrays.md) | Grow, shrink, and shell parts, round the seams between them, and repeat them in rows and circles |
| [Curves, profiles and sweeps](curves-profiles-sweeps.md) | Sweep, extrude, and revolve curves and flat profiles into graded solids |
| [Sketching and extruding](sketching.md) | Draw parametric 2D sketches in Python, place them on planes, and extrude, revolve, and loft them |
| [Deforming space](deforming-space.md) | Lean, twist, bend, and warp a part without rebuilding it |
| [Physical surface relief](surface-relief.md) | Turn an image or a Python pattern into raised, printable relief on a selected region |

Each guide assumes you have completed [Getting Started](../introduction/getting-started.md). Surface relief also uses the region selection described in [Selecting triangle-mesh patches](../imports/mesh-selection.md).
