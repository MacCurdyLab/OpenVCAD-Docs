# Primitive catalog

```{include} ../_guide-sidebar-compiler-membership.md
```

Every OpenVCAD design starts from **leaf nodes**: the primitives at the bottom of the tree that define geometry. This page shows each one with a render, a link to its Python API entry, and the example script it came from. Where a primitive has more than one useful form, use the arrows on its image to step through them.

Leaves combine with booleans, transforms and the other operations in this section, and each one carries attributes like any other node. If those are new to you, start with [Getting Started](../introduction/getting-started.md). Every example lives in `examples/geometry/` and runs on its own.

## Lattices

```{tip}
**Building a lattice? Start with the [Metamaterials](../metamaterials/index.md) guides.** The `pyvcad_metamaterials` package builds TPMS, strut, plate and stochastic lattices, fills parts with them, grades them, and maps them onto curved surfaces. The [TPMS and lattice catalog](../metamaterials/catalog.md) shows every built-in cell.
```

The two leaves below are lower level. They describe a beam lattice one beam at a time, written by hand or read from a 3MF file. Reach for them when you already have explicit node and beam lists, such as a lattice designed in another tool.
