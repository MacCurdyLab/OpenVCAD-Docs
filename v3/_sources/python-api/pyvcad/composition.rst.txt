Tree — composition nodes
==========================

**Composition nodes** are non-:class:`Leaf` nodes that each **own** one or more child subtrees. They describe how pieces are placed and combined in space: rigid transforms, mirrors, warps and tilings, sums and mixes of fields, constructive solid geometry (union, intersection, difference and bbox variants), offsets and shells.

Use them to assemble and modify designs built from :doc:`leaves` without duplicating underlying primitives.

Booleans can be blended where their children meet. ``Union``, ``Intersection`` and
``Difference`` take a ``blend_radius`` (a number, or a field with bounds, where 0 means a sharp
edge) and a ``profile``:

.. code-block:: python

   import pyvcad as pv

   plate = pv.RectPrism(pv.Vec3(0, 0, 0), pv.Vec3(14, 14, 3))
   post = pv.Cylinder(pv.Vec3(0, 0, 6.5), 3.0, 10.0)
   joint = pv.Union([plate, post], blend_radius=2.0, profile=pv.BlendProfile.circular)

A :class:`MappedStructureCollection` is a :class:`Union` of mapped lattices that keeps each
member's attachment scopes, so one call can set an attribute on the same component of every map.
The scope objects below are returned by its ``struts``, ``joints``, ``plates`` and ``shell`` properties.
