Curves and Profiles
===================

Parametric curves in 3D, with planar curves as a special case, and the frames that carry a profile
along them. Points can be passed as tuples, lists, ``Vec3``, ``Vec2``, ``Point2`` or NumPy arrays;
batched results come back as NumPy arrays. Curves never change after construction, so one curve can
be shared by many nodes.

Construction geometry
---------------------

Closed-form intersections, tangents and corner treatments. Lines are infinite lines through two
points and circles are a centre and a radius; every function returns all of its solutions, in a
stated order, as NumPy arrays.

Curves from data
----------------

Mesh paths (``MeshPath.to_curve()``), mesh and selection borders (``SurfaceMesh.boundary_loops()``,
``MeshSelection.boundary_loops()``) and node contours all return ordinary curves.
``Profile.cross_section()`` gives the region of a slice instead of its outlines.
