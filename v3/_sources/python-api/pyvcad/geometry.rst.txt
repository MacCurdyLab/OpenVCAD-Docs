Geometry
========

2D and 3D geometry types that the tree nodes are built on. Some are inputs you build directly: vectors
and polygons, meshes and CAD models, height fields for surface relief, the ``CellMap`` that bends a
lattice to a part, unit cells, and seed points with their surface Voronoi diagrams. Others are
helpers for custom geometry and analysis, such as hexahedral and tetrahedral meshing.
