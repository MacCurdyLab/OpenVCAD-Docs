Tree — leaf nodes
=================

**Leaves** are terminal :class:`Node` subclasses: they do not wrap other nodes as children. They are where concrete implicit geometry and sources live—analytic primitives, meshes, CAD imports, lattices, extruded profiles, and signed-distance fields.

The enums documented next to a node configure that node. Classes that are not nodes themselves, such as the beams and balls of a :class:`BeamLattice`, the 3MF import helpers, and the component and provenance records of the mapped and stochastic lattices, are grouped at the end under `Supporting types (not nodes)`_.

Nodes that combine or transform subtrees are **composition** operators; see :doc:`composition`.

Stochastic lattices
-------------------

Non-periodic Delaunay or Voronoi lattices built from world-space seed points and confined to a host
:class:`Node`. They take the host as an input but, like the other lattices, are terminal geometry.
See :func:`sample_poisson_seeds`, :func:`blend_seed_sets` and :func:`jitter_seed_sites` on the
:doc:`geometry` page for making seed sets.
