Built-in Modules
================

These helpers register the conversion sets bundled with the resolver package:
foaming filaments (TPU, PLA), J750 Shore hardness and modulus/toughness,
Stratasys RadioMatrix HU calibration, generic RGB/RGBA color, and vector
component splitting and joining. Use them to populate the registry before
calling :func:`pyvcad_attribute_resolver.adapt`.

Data generation
---------------

Offline helpers that regenerate the fitted models and figures behind the J750
modules. The registered conversions use the stored results, so you only need
these when changing the source data.
