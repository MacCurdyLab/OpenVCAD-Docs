``pyvcad_compilers`` module
===========================

Python bindings for classes that **compile** an implicit ``Node`` tree into
concrete outputs: inkjet and vat slice stacks, slicer projects, OpenVDB grids,
and simulation meshes. Each compiler prepares the tree itself, so pass the root
as you built it. Start with :doc:`overview` for what “compiler” means here, then
:doc:`compilers` and :doc:`utilities` for the API.
