Utilities
=========

.. currentmodule:: pyvcad_compilers

The color pipeline holds the color-correction steps (gamma, ICC profile and CMYK affinity blend)
that :class:`ColorInkjetCompiler`, and :class:`GCVFCompiler` in color mode, apply to ``color_rgba``
samples. Pass a :class:`ColorPipelineOptions` to either compiler to switch steps on or off.
:class:`ColorPipeline` itself lists the bundled ICC profiles.
