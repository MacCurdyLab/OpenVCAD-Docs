Color palettes
--------------

.. py:data:: raw_color_palettes
   :type: dict[str, list[tuple[int, int, int]]]

   Named color palettes: ``"grayscale"``, ``"jet"``, ``"rainbow"``, ``"viridis"``, ``"cividis"``
   and ``"magma"``. Each value is a list of ``(r, g, b)`` stops with channels in 0-255, ordered from
   the low end of the scale to the high end. Add an entry to make a custom palette available to
   :func:`get_color_palette`.
