Cell maps
=========

A cell map is an immutable coordinate layout: a box, a cylinder, a spherical
band, or a curvilinear volume on top of a surface. Every structure builder
takes one. The returned objects are ``pyvcad.CellMap`` or
``pyvcad.CellMapCollection`` instances.

Raw OCP shapes
--------------

CadQuery shapes are converted with ``pyvcad.CADModel.from_cadquery``. Raw
OCP shapes use the optional ``pyvcad_metamaterials.occ`` adapters, which need
the ``cad`` extra (``pip install "pyvcad-metamaterials[cad]"``).
