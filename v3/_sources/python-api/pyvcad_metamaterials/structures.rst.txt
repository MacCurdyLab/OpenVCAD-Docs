TPMS, strut, and face lattices
==============================

.. currentmodule:: pyvcad_metamaterials

TPMS lattices
-------------

Every TPMS builder returns a ``pyvcad.MappedImplicitLattice`` (or a
``pyvcad.MappedStructureCollection`` for a multi-map collection) in either
``"sheet"`` or ``"solid"`` mode.

.. autofunction:: tpms

.. autodata:: TPMS_NAMES
   :no-value:

   Names accepted by :func:`tpms`: ``fischer_koch_s``, ``frd``, ``gyroid``,
   ``iwp``, ``lidinoid``, ``neovius``, ``schwarz_d``, ``schwarz_p``,
   ``split_p``.

----------------------

Every strut builder returns a ``pyvcad.MappedGraphLattice`` (or a
``pyvcad.MappedStructureCollection`` for a multi-map collection).

   :no-value:

   ``columns``, ``cubic``, ``diamond``, ``fcc``, ``fluorite``,
   ``hex_prism_central_axis``, ``hex_prism_diamond``, ``hex_prism_edge``,
   ``hex_prism_laves``, ``hex_prism_vertex_centroid``, ``isotruss``,
   ``kelvin``, ``oct_vertex_centroid``, ``octet``, ``reentrant_3d``,
   ``reentrant_hex_prism``, ``rhombic_dodecahedron``,
   ``rotated_square_prism_edge``, ``rotated_triangular_prism_edge``,
   ``tet_oct_vertex_centroid``, ``triangular_prism_edge``,
   ``truncated_cube``, ``weaire_phelan``.

Face (plate and wall) lattices
------------------------------

Face builders return a ``pyvcad.MappedFaceLattice`` (or a
``pyvcad.MappedStructureCollection`` for a multi-map collection) whose
center surfaces are thickened into walls.

.. autofunction:: face_lattice

.. autodata:: FACE_LATTICE_NAMES
   :no-value:

   Names accepted by :func:`face_lattice` and :func:`face_unit_cell`: ``plate``,
   ``simple_cubic_plate``, ``body_centered_cubic_plate``,
   ``face_centered_cubic_plate``, ``cubic_octet_plate``,
   ``hexagonal_honeycomb``, ``reentrant_honeycomb``, ``square_honeycomb``,
   ``rotated_square_honeycomb``, ``triangular_honeycomb``,
   ``rotated_triangular_honeycomb``.

Building graph cells from seeds and tessellations
--------------------------------------------------

These builders return the same edge lists as the catalog cells (origin-centred,
spanning ``[-0.5, 0.5]``), so their results go straight into
:func:`graph_lattice`; :meth:`PeriodicTessellation.face_cell` returns a
``pyvcad.FaceUnitCell`` for :func:`face_lattice`. See
:doc:`/guides/metamaterials/custom-unit-cells` for a walkthrough.

.. autofunction:: periodic_voronoi

.. autofunction:: periodic_bonds

.. autofunction:: tessellation

.. autodata:: TESSELLATION_NAMES
   :no-value:

   Names accepted by :func:`tessellation`: ``cube``, ``hexagonal_prism``,
   ``reentrant_hexagonal_prism``, ``triangular_prism``,
   ``rotated_triangular_prism``, ``rotated_square_prism``, ``tet_oct``,
   ``truncated_cube``.

.. autodata:: GRAPH_RULES
   :no-value:

   Rules accepted by :meth:`PeriodicTessellation.edges`: ``edges``,
   ``cell_vertex_centroid``, ``facet_vertex_centroid``, ``dual``,
   ``central_axes``.
