Headless (no GUI)
=================

These functions render off-screen and write image, animation or diagram files.
They are suited to automation, tests, and batch pipelines where no window
should appear. The CamelCase names (``Render_Image``, ``Render_Turntable_Animation``,
``Render_Sweep_Animation``, ``Render_Tree_Diagram``, ``Render_Tree_Legend``) are
aliases kept for older scripts.

Tree diagrams
-------------

Save a Mermaid diagram of a design's node tree (built by
:class:`pyvcad.TreeDiagram`) as ``.mmd`` source, or as ``.svg`` / ``.png``
through the Mermaid CLI (``mmdc``).

Profile plots
-------------

Check a 2D sketch before turning it into a solid: :func:`plot_profile` draws profiles, sketches and
curves with matplotlib, with holes, loop directions and corners marked. See
:doc:`../../guides/modeling/sketching`.

.. autofunction:: plot_profile

Signed distance slices
----------------------

Plot a principal-plane slice of a node's signed distance field with
matplotlib. :func:`VisualizeSDF` is the one-call version; :class:`SDFSliceSampler`
and :func:`draw_sdf_slice` let you sample and draw slices yourself, for example
to step through offsets or embed the plot in your own figure.
