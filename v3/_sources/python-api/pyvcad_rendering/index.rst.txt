``pyvcad_rendering`` module
============================

The ``pyvcad_rendering`` package provides the interactive viewer, the compiler
export wizard and the mesh patch picker; headless images, turntable and sweep
animations; tree diagrams and signed-distance slice plots; mesh-selection files;
and VTK exports of sampled geometry. For most scripts you only need a small set
of entry points; they are grouped by how you run them in the sections below.

.. code-block:: python

   import pyvcad as pv
   import pyvcad_rendering as viz

   part = pv.Sphere(pv.Vec3(0, 0, 0), 10)
   viz.render_image(part, "sphere.png")   # headless
   viz.render(part)                       # interactive window
