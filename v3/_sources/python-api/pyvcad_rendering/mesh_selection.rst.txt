Mesh selections
===============

Helpers for building, saving and replaying triangle selections on a
``pyvcad.SurfaceMesh`` without opening a window. A selection file records the
triangle IDs together with a fingerprint of the mesh they belong to, so it can
refuse to load onto changed geometry, and the recipe that made it, so a point or
ray seed can be rerun after a deliberate remesh. Use
:func:`~pyvcad_rendering.select_mesh_patch` (see :doc:`interactive`) to pick a
selection by hand. See the :doc:`/guides/imports/mesh-selection` guide for a
walkthrough.
