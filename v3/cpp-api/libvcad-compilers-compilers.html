class CompilerBase#
#include <compiler_base.h>

Abstract base of every OpenVCAD compiler.

A compiler turns a node tree into an output format (slice images, archives, meshes, slicer projects, VDB grids). Each concrete compiler stores its root and settings at construction and does all work in compile(), which prepares the root itself. The base class owns the progress/status callbacks, cancellation, voxel-culling switches and the export statistics printed by report_stats().

Subclassed by ColorInkjetCompiler, GCVFCompiler, MaterialInkjetCompiler, MultiMaterialVatCompiler, MyersonCompiler, SimulationCompiler, SlicerProjectCompiler, VatCompiler, VdbCompiler

class GCVFCompiler : public CompilerBase#
#include <gcvf_compiler.h>

Compiles an OpenVCAD node tree into a legacy Stratasys GCVF archive.

GCVFCompiler is a meta-compiler that selects either the MaterialInkjetCompiler or ColorInkjetCompiler backend, from the attributes advertised by the design or explicitly through set_backend() when the design carries both. It then packages the emitted PNG stack, z-buffer, STL mesh, bounding-box metadata, and XML configuration into a .gcvf zip archive that matches the legacy exporter layout.

class MyersonCompiler : public CompilerBase#
#include <myerson_compiler.h>

Generates per-material 1-bit BMP stacks for the legacy Myerson workflow.

This compiler consumes the VOLUME_FRACTIONS attribute and writes one bitmap stack per exported material. Each bitmap uses a fixed-width Myerson-style canvas, optional Y padding from taper/extra-width settings, and the legacy layer filename format. Each inside voxel gets one material by stochastic sampling of its volume fractions; a void (ID 0) pick leaves the voxel empty in every stack.

Each inside sample draws one material from its volume fractions by deterministic weighted stochastic sampling. The output always contains a FloatGrid level set named “surface”. It can optionally include a BoolGrid named “occupancy” and typed attribute grids for scalar, vec3, and vec4 attributes. volume_fractions is never exported, and attributes of any other type are skipped.
