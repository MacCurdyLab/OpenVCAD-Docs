class ColorPipeline#
#include <color_pipeline.h>

Converts sRGBA colors into inkjet ink choices (cyan, magenta, yellow, black, white, clear).

Colors pass through the steps enabled in ColorPipelineOptions, are split into CMYKW fractions, and are then either sampled to one ink (process()) or returned as probabilities (ink_probabilities()). Each instance owns lcms2 state; use clone() to give each thread its own copy.

std::array<float, 6> ink_probabilities(const glm::vec4 &rgba_color) const#

Converts an sRGBA color into CMYKW+Clear ink probabilities.

Applies the same correction and CMYKW logic used by process(), but returns continuous probabilities instead of stochastically selecting one ink channel. Components are ordered Cyan, Magenta, Yellow, Black, White, Clear.

Parameters:

rgba_color – sRGBA color with components in [0, 1].

Returns:

CMYKW fractions scaled by alpha, followed by clear = 1 - alpha.

ColorSampleResult process(const glm::vec4 &rgba_color) const#

Converts sRGBA to CMYKW and stochastically picks one ink.

Applies the configured ColorPipelineOptions before CMYKW conversion. When alpha is below 1, the color is replaced by the clear ink with probability 1 - alpha; palette_index still reports the CMYKW pick.

Parameters:

rgba_color – sRGBA color with components in [0, 1].

Returns:

The picked ink.

enum class PrusaVolumeFractionPaletteMode#

Strategy used to pick VOLUME_FRACTIONS palette recipes.

Uniform chops the fraction range into max_palette_size equal bins and places one recipe at each bin center, so every region spans the same fraction width regardless of how the samples are distributed. Adaptive runs a median cut over the sampled fraction histogram, which spends recipes where the samples actually are but only subdivides in halves, so bin widths are uneven unless max_palette_size is a power of two. Uniform binning is only defined for a single degree of freedom, so a two-material export honours it and any export with three or more materials falls back to Adaptive.

Values:

enumerator Uniform#

Equal-width bins; two-material exports only.

enumerator Adaptive#

Median cut of the sampled fraction histogram.

namespace ErrorDiffusion3D#

Utilities for quantizing arbitrary multi-channel voxel fields.

Functions

void dither(std::vector<float> &probabilities, const std::vector<uint8_t> &occupied, const std::vector<uint8_t> &eligibility, std::vector<uint8_t> &assignments, size_t x_dim, size_t y_dim, size_t z_dim, size_t channel_count, const std::function<void()> &cancellation_check = nullptr, const std::function<void(double)> &progress_callback = nullptr)#

Quantizes a dense multi-channel voxel field with 3D error diffusion.

Voxels are traversed in ascending Z with a serpentine X scan. Quantization error is distributed to unprocessed occupied voxels in the current and next Z planes. When eligibility is supplied, each channel is diffused only to voxels that allow that channel.

Parameters:

  • probabilities – Flat voxel-major probability tensor. Modified in place.

  • occupied – Flat voxel occupancy mask.

  • eligibility – Optional flat voxel-major channel mask. An empty vector means every channel is eligible at every occupied voxel.

  • assignments – Receives one selected channel per voxel.

  • x_dim – Number of voxels along X.

  • y_dim – Number of voxels along Y.

  • z_dim – Number of voxels along Z.

  • channel_count – Number of channels per voxel. Must be in [1, 256].

  • cancellation_check – Optional callback invoked before each Z plane.

  • progress_callback – Optional callback receiving progress in [0, 1].

#include <parallel_voxel_loop.h>

Runs a per-layer callback over z layers in parallel with TBB.

Each worker thread gets its own clone of the root, made the first time that thread runs a layer, so callbacks can sample the tree without sharing node state. The root must be prepared before run() is called.

void run(long z_dim, const LayerCallback &layer_fn, const std::atomic<bool> &cancelled, const std::function<void(double)> &progress_callback = nullptr, ThreadUsageTracker *thread_usage_tracker = nullptr)#

Runs parallel_for over [0, z_dim).

For each z, calls layer_fn with a thread-local clone of root. Checks cancellation between layers and reports progress after each layer completes.

Progress is the number of finished layers divided by z_dim, so the last report of an uncancelled run is exactly 1.0. Reports are serialized but may arrive from any worker thread. Once cancelled is set, layers not yet started are skipped; run() returns without throwing.

Parameters:

  • cancelled – Flag checked before each layer.

  • thread_usage_tracker – Optional; records each worker thread that runs a layer.
