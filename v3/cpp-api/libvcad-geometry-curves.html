Geometry — curves and profiles#

Parametric curves, their frames, closed 2D profiles, and curves made from meshes and node contours. The solids built from them (Tube, Extrude, Revolve, Sweep) are on the leaves page.

Curves#

class Curve#
#include <curve.h>

An immutable parametric curve in 3D space.

Every curve maps a parameter t in domain() to a point. Planar curves are the case where every point lies in one plane (plane_normal()); 2D input is placed at z = 0.

The base class owns the machinery every curve shares. Each concrete curve splits itself into pieces: parameter intervals with a rigorous bounding box and a bound on how far the piece strays from its chord. From these the base class builds, once:

  • an AABB tree for closest-point queries;

  • a cumulative arc-length table (exact for straight pieces, 8-point Gauss-Legendre otherwise);

  • the bounding box and the plane of the curve.

Closest point: pieces whose box is farther than the best distance found so far are pruned, and each remaining piece is refined with safeguarded Newton iterations on (c(t) - p) . c’(t). The piece holding the true minimiser is never pruned, so the result is exact to Newton tolerance (about 1e-12 relative). The exception is a query point near the centre of curvature of a curved piece, where Newton can settle on a local minimum of that piece; the distance is then within twice the piece’s deviation from its chord of the true minimum. BezierCurve and BSplineCurve pieces deviate by at most 1e-5 of the control-point box diagonal. Straight pieces are projected in closed form and ArcCurve overrides the search with a closed form, so LineSegment, PolylineCurve and ArcCurve are exact.

Curves never change after construction, so every query is lock-free and curves are shared between node clones and threads. (Polyline2, the legacy 2D polyline, is the one exception: its in-place edits rebuild the curve and must not overlap other use of the same object.)

Subclassed by ArcCurve, BSplineCurve, BezierCurve, CompositeCurve, LineSegment, PolylineCurve, TrimmedCurve

class PolylineCurve : public Curve#
#include <polyline_curve.h>

A chain of straight segments through a list of points, open or closed.

The parameter runs over [0, n] for n segments: t = i + s lies on segment i at fraction s. A closed polyline adds the segment from the last point back to the first; a repeated first point at the end of the input is dropped. Closest points, lengths and the bounding box are exact; an AABB tree over the segments keeps closest-point queries logarithmic.

class ArcCurve : public Curve#
#include <arc_curve.h>

A circular arc, or a full circle, with t in [0, 1].

The arc lies in the plane through center with the given normal. Angles are measured in that plane from a reference direction: world +X projected into the plane (world +Y when the normal is along X), turning counter-clockwise about the normal. So with the default normal +Z, angles are the usual polar angles in the XY plane. The arc runs from start_degrees to end_degrees; a negative sweep runs clockwise, and a sweep of 360 degrees (either sign) is a closed circle. Closest points, lengths and bounding boxes are exact.

class CurveFrames#
#include <curve_frames.h>

Rotation-minimizing frames along a curve.

The frames turn as little as possible about the tangent, so a profile carried along the curve does not twist on its own. They are computed with the double-reflection method (Wang, Juttler, Zheng and Liu, 2008) on a table of points evenly spaced in arc length, and evaluated at any parameter with one more reflection from the table entry before it, so they vary continuously.

Initial frame: the binormal starts along up made perpendicular to the start tangent. Without up, a planar curve uses its plane normal (the frames then stay in the plane) and other curves the world axis least aligned with the start tangent.

Closed curves: carrying the frame once around generally returns it rotated by an angle (the holonomy). That angle is spread evenly in arc length, so the frames match at the seam with the smallest constant twist rate.

Immutable after construction; frame() is thread-safe.

class Profile#
#include <profile.h>

An immutable closed region of the XY plane bounded by closed curves, possibly with holes.

A profile is the cross-section that Extrude, Revolve and Sweep turn into solids. Its boundary is a set of closed, planar loops at z = 0 (any Curve type); loops must not cross themselves or each other. Nesting decides what is inside: at construction every loop that lies inside an even number of other loops is an outer boundary and is turned counter-clockwise, and every other loop is a hole and is turned clockwise.

Signed distance is computed from the curves themselves: the distance to the nearest loop (each loop answers from its own exact closest-point search) with the sign from the side of the nearest boundary point, using the bisector of the two tangents at a corner. It is exact for every profile, to the closest-point accuracy of its curves (see Curve).

Operations:

  • Booleans (Union, Intersection, Difference) run on tessellations with Clipper2 for robust topology, then map every result edge back to the input curve it came from, so the result loops are pieces of the input curves (TrimmedCurve) joined at intersection points refined on the curves. Loops that cannot be recovered fall back to the polygon, which is within the tolerance.

  • offset() runs Clipper2 on the tessellation. A round offset of a profile made only of straight edges and circular arcs is also built exactly (edges moved along their normals, arcs made concentric, convex corners joined by arcs) and returned when it agrees with Clipper2’s result (same number of loops, same area within the tolerance). Otherwise the result is Clipper2’s polygon, within the tolerance.

  • fillet() rounds the corners between straight pieces with exact tangent arcs.

The default tolerance is min(0.001, 1e-4 x the profile size), in model units (mm). Immutable after construction: queries are thread-safe and profiles are shared between nodes.

static std::shared_ptr<Profile> from_curves(const std::vector<std::shared_ptr<const Curve>> &curves, double tolerance = 0.0)#

Builds a profile from loose curves by chaining them end to end into closed loops.

Closed curves are loops on their own. Open curves are joined where an end of one lies within tolerance of an end of another (either may be reversed); a small gap is bridged with a straight segment. Where more than two ends meet, the nearest end is taken. This is how drawings imported from other tools, whose pieces come in any order and direction, become profiles.

Parameters:

  • curves – The curves, in the XY plane, in any order and direction.

  • tolerance – The largest gap to close; 0 uses 1e-6 of the curves’ overall size.
