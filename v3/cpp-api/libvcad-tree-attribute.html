How faithfully this node’s value, including its whole subtree, matches the true signed distance.

Composes the node’s own operation with its children’s accuracy, so the root’s answer describes the whole tree. exact and bound promise that the value clamped to the bandwidth is lipschitz_bound()-Lipschitz and that values outside the bounding box are at least the per-axis distance to it (see DistanceAccuracy). Only valid after prepare(); some nodes decide from what prepare()

measured. The default is approximate, so a node without an override can only disable optimizations that rely on the guarantee.

The child’s accuracy: only attributes change, the value, box and band are the child’s. Approximate if the child was last prepared with a narrower band than this node (a child shared with another parent), since its value would then stop short of this node’s band.

The accuracy of the subtree rooted at this node.

class Convolve : public Unary#
#include <convolve.h>

A unary node that convolves the attributes of its child node using a defined kernel.

Convolve intercepts sample() calls and blends/convolves the child’s attributes over a local region using an arbitrary kernel. The signed distance field (geometry) is passed through unmodified.

Under the hood, prepare() precomputes a dense typed voxel grid of the child’s targeted attributes using the shared AttributeVoxelGrid utility. At sample time each kernel tap becomes a cheap flat-memory trilinear grid lookup instead of a full child->sample() traversal, which makes the node orders of magnitude faster than a naive implementation.

Convolve is the generic, flexible sibling of the specialized Blend node; both share the same precomputation utility but have independent sample-time logic. Use Blend as a shorthand for the common box-blend case (where a separable-blur fast path lives entirely in prepare() and sample() becomes a single trilinear lookup). Use Convolve for arbitrary kernel weights or non-blur operations (sharpen, derivative, etc.).

The internal grid defaults to the voxel_size passed to prepare(). Users can supply a sparser override_voxel_size in the constructor to reduce memory cost for large scenes; trilinear interpolation at sample time still produces smooth output.

class Blend : public Unary#
#include <blend.h>

A fast, specialized unary node for locally blending varying attributes of its child.

Unlike the more general Convolve node (which at sample time performs a weighted sum over all kernel taps using cheap trilinear grid lookups), Blend precomputes the child’s targeted attributes onto a dense voxel grid during prepare(), applies a masked separable box blur along X, Y, Z (optionally repeated to approximate a smoother Gaussian-like ramp), and then serves sample() by doing a single trilinear lookup into the pre-blurred grid combined with a single child sample() call. This turns per-sample work into O(1) and amortizes the blur work across all downstream sample() calls.

Blend and Convolve are siblings that share the underlying AttributeVoxelGrid utility for parallel-filling typed per-attribute buffers. Blend keeps the separable-blur fast path; Convolve keeps its generic per-sample weighted-sum over arbitrary kernels.

The node is intentionally a no-op in regions where the targeted attributes are locally constant (linear blurs preserve constants), so users can safely apply it over an entire assembly and only see change near boundaries where attributes differ.

The internal grid defaults to the voxel_size passed to prepare(). Users can supply a sparser override_voxel_size in the constructor to reduce memory cost for large scenes; trilinear interpolation at sample time still produces smooth output.
