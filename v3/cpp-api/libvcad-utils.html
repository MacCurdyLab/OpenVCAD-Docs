class TreeSampler#
#include <tree_sampler.h>

Samples a node tree onto a regular voxel grid or at arbitrary points.

The grid covers the root’s bounding box grown by two voxels on every side. Voxel (x, y, z) sits at bbox_min + (x, y, z) * voxel_size, and every flat grid array uses index x + y * nx + z * nx * ny (x fastest), with (nx, ny, nz) from sample_dimensions(). Grid samples are computed in parallel on per-thread clones of the root and cached, so repeated calls are cheap. The root, voxel size and material definitions are fixed at construction; to change any of them, build a new TreeSampler.

std::vector<float> as_narrow_band_signed_distance_array(const ProgressCallback &progress = nullptr, float band_voxels = 3.0f, int coarse_factor = 4)#

The signed distance field on the same grid as as_signed_distance_array(), evaluated exactly only near the surface.

The grid is split into coarse cells of coarse_factor^3 voxels. Each cell is probed at its corners and center. A cell is filled instead of evaluated only when the root’s distance bound (Node::distance_accuracy() and lipschitz_bound(), read through DistanceCertifier) proves that every voxel in it lies on the probes’ side of the surface with a value beyond band_voxels voxels: with L the Lipschitz bound and T the root’s sample bandwidth, every probe’s value clamped to T (T for no value) must exceed the band by L times the distance from the cell’s voxels to the nearest probe. A filled cell holds the smallest probed distance (at most T) with the probes’ sign, or the “no value” marker when no probe had a value. Every other cell is evaluated voxel by voxel, exactly as as_signed_distance_array() does.

When the root is approximate, its bound is not finite, culling is switched off (OPENVCAD_DISABLE_CULLING=1) or the bandwidth is too small to prove any cell, the full field is sampled instead (and cached as as_signed_distance_array()). Finally, any filled cell that the contour or its normals would read (both ends of every sign-changing edge and their six neighbours) is evaluated, repeatedly; this only happens for bands narrower than 2 L voxels.

Voxels within the band therefore hold exactly the full field’s values, every voxel has the full field’s sign, and contouring the result at 0 gives the same surface and gradient normals, in a fraction of the time for designs with empty space. Use the full field for anything that reads values deep inside or far outside (volume rendering, offsets).

The result is cached; when the full field has already been sampled it is returned instead. culling_stats() describes the pass (sampled = voxels evaluated).

Parameters:

  • progress – Optional progress callback receiving integer values from 0 to 100.

  • band_voxels – Half-width, in voxels, of the band kept exact. Defaults to 3.

  • coarse_factor – Coarse cell size in voxels (>= 2). Defaults to 4.

Returns:

A flat array in the layout of as_signed_distance_array().

openvdb::FloatGrid::Ptr as_openvdb_sdf_grid_block_culled(const ProgressCallback &progress = nullptr)#

Sample a narrow-band OpenVDB SDF with per-block exterior culling.

Same transform / half-width conventions as as_openvdb_sdf_grid(), but partitions the domain into blocks of 8^3 voxels and skips a block, or an octant of it down to 4^3 voxels, when a probe at its centre proves through the root’s distance bound (DistanceCertifier) that every voxel in it has a value beyond the half-width. The grid is therefore the same as as_openvdb_sdf_grid(), which it falls back to when the root is approximate, its bound is not finite, culling is switched off (OPENVCAD_DISABLE_CULLING=1) or the bandwidth is too small to prove anything. Prefer as_openvdb_sdf_grid_narrow_band() for meshing; this method is useful when a coarse-to-fine pass is unnecessary. culling_stats() describes the pass.

Parameters:

progress – Optional progress callback receiving integer values from 0 to 100.

Returns:

A FloatGrid containing the signed-distance field.

openvdb::FloatGrid::Ptr as_openvdb_sdf_grid_narrow_band(const ProgressCallback &progress = nullptr, int coarse_factor = 4)#

Sample a narrow-band OpenVDB SDF via coarse-to-fine culling.

Samples a lattice of coarse-cell corners (shared by neighbouring cells) plus each cell center, and skips every cell whose probes prove through the root’s distance bound that no voxel in it has a value within the half-width, with the same rule as as_narrow_band_signed_distance_array(). The remaining cells are evaluated; in cells wider than 4 voxels, octants down to 4^3 voxels are again skipped when a probe proves them. The grid is the same as as_openvdb_sdf_grid(), which it falls back to under the same conditions as as_openvdb_sdf_grid_block_culled(). Preferred entry point for surface meshing. culling_stats() describes the pass.

Parameters:

  • coarse_factor – Integer coarsening factor (>= 2). Defaults to 4.

Returns:

A FloatGrid containing the signed-distance field.

class DistanceCertifier#

Turns one evaluate() probe of a prepared tree into a ball proven free of material.

class LayerCuller#
#include <voxel_culling.h>

Marks, layer by layer, the voxels of a grid that may hold material.

Each layer is covered by square tiles that are split as a quadtree down to a leaf size. A tile is skipped when a certified empty ball (its own probe’s or an ancestor’s) contains every voxel of it; it is sampled whole, without more probes, when a certified full ball contains it; leaves that prove nothing are sampled. A tile is only probed when a probe could prove it empty at all, so the large tiles inside the root’s box cost no evaluations. Tile boxes come from the exact coordinates the caller samples, so a skipped voxel is one whose sample() would report no material.

The caller keeps its own loops and skips voxels whose mask entry is 0, which keeps the order of the remaining sample() calls exactly as before. Choose the mask layout that matches the caller’s innermost loop so the mask is read contiguously. Probes use the caller’s thread-local root, so build_layer() is safe to call from many threads at once.

class AttributeVoxelGrid#
#include <attribute_voxel_grid.h>

Shared dense voxel grid of precomputed child-node attributes.

A typed, mask-aware 3D grid used by the Blend and Convolve nodes to cache the result of a child’s attribute evaluation across space. The grid stores samples at grid “corners” (the world position of voxel (i,j,k) is origin + (i,j,k) * voxel_size), which means any query point that aligns with a corner resolves without interpolation, preserving exact numerical parity with direct child sampling in the aligned case.

The utility handles:

  • Parallel filling via a per-thread cloned child prototype and TBB.

  • Lazy per-attribute type discovery during the fill (scalar, vec3, vec4, or volume fraction map), with per-attribute mutexes to allow safe concurrent allocation of typed buffers.

  • Trilinear interpolation at sample time, mask-weighted so cells with no source data do not drag neighbors toward zero.

  • A separable 1D masked box blur (prefix-sum based) that Blend uses to produce a Gaussian-like ramp across attribute boundaries while keeping per-sample cost O(1).

The default AUTO strategy therefore prefers the Instance Number (0020,0013) tag stored in each file and only falls back to filenames when that tag is missing or ambiguous.

Values:

enumerator AUTO#

Sort by Instance Number when every file carries a unique one, otherwise sort by filename.

enumerator INSTANCE_NUMBER#

Always sort by Instance Number (0020,0013); throws when the tag is missing or duplicated.

enumerator SLICE_POSITION#

Sort by the geometric slice position; throws when the position cannot be determined.

Uses Image Position Patient (0020,0032) projected onto the slice normal derived from Image Orientation Patient (0020,0037), falling back to Slice Location (0020,1041). Not used by AUTO because many non-clinical exports write a constant (or absent) patient position for every slice.

enumerator FILENAME#

Sort by filename only, using a natural (digit-aware) comparison. Reads no metadata.

enum class Easing#

Shaping curves that map [0, 1] onto [0, 1], used to ease ramps and other normalized fields.

Every curve starts at 0 and ends at 1 and never decreases, so an eased field keeps the range of its input. Inputs outside [0, 1] are clamped first.

  • linear: t.

  • smoothstep: 3t² − 2t³ (zero slope at both ends).

  • smootherstep: 6t⁵ − 15t⁴ + 10t³ (zero slope and curvature at both ends).

  • power: t^p with shape p > 0 (p > 1 starts slowly, p < 1 starts quickly).

  • sine: (1 − cos πt) / 2 (zero slope at both ends).

  • exponential: (e^{kt} − 1) / (e^k − 1) with shape k ≠ 0 (k > 0 starts slowly, k < 0 starts quickly).
