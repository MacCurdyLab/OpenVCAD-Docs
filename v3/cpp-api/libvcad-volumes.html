struct FieldSamplingOptions#

Outside-domain settings used when creating or diagnostically sampling a field.

boundary_clamp requires a finite non-negative max_distance in dataset-coordinate units. If a constant is also supplied, it is used only beyond the clamp band. Constant values are expressed in stored field coordinates; vector_transform is applied before a vector is returned.

class TetrahedralDomain#
#include <unstructured_field.h>

Immutable validated TET4 domain with shared point-location and boundary queries.

Input containers are copied. Cell winding is normalized, all barycentric work is performed in double precision, and prepared CGAL query structures are read-only and safe to share among independently cloned attributes.

class UnstructuredFieldDataset#
#include <unstructured_field.h>

Solver-neutral named scalar/vector results sharing one immutable TET4 domain.

The default position and vector transforms are identity. position_transform maps consuming-node coordinates into dataset coordinates. vector_transform maps stored vector components into the consuming-node coordinate basis; it never deforms the domain. Unit conversion is therefore explicit rather than inferred from metadata.

class XDMFFieldLoader#
#include <xdmf_field_loader.h>

Loader for OpenVCAD’s documented XDMF 3/HDF5 TET4 result-field subset.

Supports direct HDF-backed Tetrahedron topology, XYZ geometry, and Node/Cell scalar or three-component vector attributes on a Uniform grid. Collections, temporal grids, mixed/HEX topology, inline XML, functions, hyperslabs, tensors, and other general XDMF features are rejected explicitly.

Public Static Functions

Load one supported uniform grid and selected fields.

Parameters:

  • xdmf_path – Path to an XDMF 3 document.

  • grid_name – Grid name. Required when the document has multiple uniform grids.

  • field_names – Field names to load, or an empty list to load all supported fields.

Returns:

A solver-neutral dataset independent of compilers and solver libraries.
