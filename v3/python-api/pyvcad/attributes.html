Attributes#

In attribute modeling, attributes are typed spatial fields. They acquire a name only when attached to a node in your Node tree. They describe quantities that vary through the interior of a part—modulus, color, material volume fractions, and more—using the same sampling idea as implicit geometry: at each point, the engine evaluates whether you are inside the solid and, when you are, evaluates the attached fields at that location.

Conceptually, each attribute implements a sample at (x, y, z) together with the signed distance d to the surface. Expression strings (see the math expressions guide) can use coordinates and d; results are aggregated under string names so renderers and compilers can pick them up consistently.

Interface you use in Python

  • Attach fields to geometry with node.set_attribute(name, attribute).

  • Use canonical names from DefaultAttributes (e.g. MODULUS, COLOR_RGBA, VOLUME_FRACTIONS) so downstream tools know which field to read.

  • ``FloatAttribute`` — one scalar per point (physical scalars, temperatures, etc.).

  • ``Vec3Attribute`` — three components per point, with composition methods for directions and displacements.

  • ``Vec4Attribute`` — four components per point (typical use: linear RGBA in [0, 1]).

  • ``VolumeFractionsAttribute`` — maps material IDs to fractions at each point; fractions should sum to 1 where mixtures apply.

  • Python function support is Numba-only. Use numba.cfunc with the signature float64(float64, float64, float64, float64). Field-valued parameters also accept a plain callable and compile it with numba for you (see as_float_attribute).

Attributes are only evaluated where the geometry exists (inside or on the surface), so expensive expressions are not run in empty space.

Examples#

The patterns below mirror the getting-started guide (lessons 4–6); they show the minimal attach-and-name workflow.

Scalar field (constant or expression)

import pyvcad as pv

cube = pv.RectPrism(pv.Vec3(0, 0, 0), pv.Vec3(10, 10, 10))
cube.set_attribute(pv.DefaultAttributes.MODULUS, pv.FloatAttribute(5.0))

cube = pv.RectPrism(pv.Vec3(0, 0, 0), pv.Vec3(10, 10, 50))
cube.set_attribute(
    pv.DefaultAttributes.MODULUS,
    pv.FloatAttribute("0.18 * z + 5.5"),
)

Scalar field (Numba function)

import pyvcad as pv
from numba import cfunc, types

@cfunc(types.float64(types.float64, types.float64, types.float64, types.float64))
def modulus_gradient(x, y, z, d):
    return 0.18 * z + 5.5

cube = pv.RectPrism(pv.Vec3(0, 0, 0), pv.Vec3(10, 10, 50))
cube.set_attribute(
    pv.DefaultAttributes.MODULUS,
    pv.FloatAttribute(modulus_gradient),
)

RGBA color field

cube = pv.RectPrism(pv.Vec3(0, 0, 0), pv.Vec3(50, 10, 10))
color = pv.Vec4Attribute("x/50 + 0.5", "-x/50 + 0.5", "x/50 + 0.5", "1.0")
cube.set_attribute(pv.DefaultAttributes.COLOR_RGBA, color)

Volume fractions (multi-material)

materials = pv.default_materials
cube = pv.RectPrism(pv.Vec3(0, 0, 0), pv.Vec3(50, 10, 10))
cube.set_attribute(
    pv.DefaultAttributes.VOLUME_FRACTIONS,
    pv.VolumeFractionsAttribute(
        [
            ("x/50 + 0.5", materials.id("blue")),
            ("-x/50 + 0.5", materials.id("red")),
        ]
    ),
)

static between()#

(first: pyvcad.pyvcad.Node, second: pyvcad.pyvcad.Node, exponent: typing.SupportsFloat | typing.SupportsIndex = 1.0, voxel_size: typing.SupportsFloat | typing.SupportsIndex = 0.5, bandwidth: typing.SupportsFloat | typing.SupportsIndex = 10.0) -> pyvcad.pyvcad.FloatAttribute

Return a field that is 0 at the first body, 1 at the second, and grades smoothly between them.

The value is d1^p / (d1^p + d2^p), with d1 and d2 the distances to the two bodies (0 inside them). Use it to grade material or a geometry parameter from one part to another, whatever their shapes. exponent = 1 gives an even grade; larger exponents hold the end values longer and switch more sharply midway. The range is [0, 1]. Choose a bandwidth at least as large as the gap between the bodies so both distances are accurate where the field grades.

Parameters:

  • first (Node) – The body where the field is 0.

  • second (Node) – The body where the field is 1.

  • exponent (float) – The power p, positive.

  • voxel_size (float) – Voxel size in mm used to prepare the bodies.

  • bandwidth (float) – Distance in mm around each body’s box where its distance is evaluated.

Example

>>> blend = pv.FloatAttribute.between(stiff_insert, soft_shell, bandwidth=30.0)
>>> fractions = pv.VolumeFractionsAttribute([(1.0 - blend, red), (blend, blue)])

static curvature()#

(body: pyvcad.pyvcad.Node, kind: object = ‘mean’, voxel_size: typing.SupportsFloat | typing.SupportsIndex = 0.5, bandwidth: typing.SupportsFloat | typing.SupportsIndex = 10.0) -> pyvcad.pyvcad.FloatAttribute

Return the curvature of a body’s surface as a field, in 1/mm (a CurvatureAttribute).

“mean” is positive on convex skin and negative in hollows (1/R on a sphere); “gaussian” is the product of the principal curvatures (negative on saddles); “maximum” is 1 / the tightest bend radius, high at tight bends and sharp edges, where a fillet or extra thickness may be needed. Use a voxel size about a quarter of the smallest radius that matters: features smaller than half the voxel size are smoothed over.

Parameters:

  • body (Node) – The node whose surface is measured; your node is not modified.

  • kind (str | CurvatureAttribute.Kind) – “mean”, “gaussian” or “maximum”.

  • voxel_size (float) – Voxel size in mm used to prepare the body.

  • bandwidth (float) – Distance in mm around the body’s box where its field is evaluated.

Example

>>> bend = pv.FloatAttribute.curvature(part, "maximum", voxel_size=0.2)
>>> part.set_attribute("curvature", bend)

ease(self: pyvcad.pyvcad.FloatAttribute, easing: object = 'smoothstep', shape: object = None) → pyvcad.pyvcad.FloatAttribute#

Return this attribute clamped to [0, 1] and passed through an easing curve.

Use it to shape a ramp or any field already normalized to [0, 1]. Every curve runs from 0 to 1 and never decreases, so the result stays in [0, 1]:

  • linear: t.

  • smoothstep: 3t^2 - 2t^3, flat at both ends.

  • smootherstep: 6t^5 - 15t^4 + 10t^3, flat and without a curvature jump at both ends.

  • power: t^p. p > 1 starts slowly, p < 1 starts quickly (default p = 2).

  • sine: (1 - cos(pi t)) / 2, flat at both ends.

  • exponential: (e^(kt) - 1) / (e^k - 1). k > 0 starts slowly, k < 0 quickly (default k = 4).

The result knows its range, so it can drive geometry (an offset or a shell thickness) without hand-written bounds.

Parameters:

  • easing (str | Easing) – The curve, by name or as a pv.Easing value.

  • shape (float | None) – The exponent p of power or the rate k of exponential; None for the default.

Example

>>> ramp = pv.FloatAttribute("z").normalize(0.0, 40.0).ease("smootherstep")
>>> late = pv.FloatAttribute("z").normalize(0.0, 40.0).ease("power", 3.0)
static from_points()#

(points: typing.Annotated[numpy.typing.ArrayLike, numpy.float64], values: typing.Annotated[numpy.typing.ArrayLike, numpy.float64], method: str = ‘idw’, neighbors: typing.SupportsInt | typing.SupportsIndex = 8, power: typing.SupportsFloat | typing.SupportsIndex = 2.0, kernel: str = ‘thin_plate_spline’, radius: object = None, smoothing: typing.SupportsFloat | typing.SupportsIndex = 0.0) -> pyvcad.pyvcad.FloatAttribute

Return a ScatteredFloatAttribute: a scalar field from values at scattered points.

Parameters:

  • points (numpy.ndarray) – (N, 3) positions in mm.

  • values (numpy.ndarray) – (N,) values, one per point.

  • method (str) – How the values fill the space between the points. “nearest” takes the value of the nearest point. “idw” averages the nearest points, closer ones weighing more: exact at the points, continuous, and always within the range of the data. “rbf” fits a smooth radial-basis-function surface through every point.

  • neighbors (int) – idw: how many nearest points are averaged.

  • power (float) – idw: how fast a point’s weight falls with distance.

  • kernel (str) – rbf: “thin_plate_spline” (smooth and global; at most 2,500 points; each sample visits every point) or “wendland” (compact: each point reaches only radius, so it scales to many points; away from the data it returns to the mean value).

  • radius (float | None) – rbf with wendland: the reach of each point in mm. None uses three times the median spacing between points.

  • smoothing (float) – rbf: 0 passes exactly through every value; larger values fit noisy data loosely (and allow repeated points).

Example

>>> sensors = np.array([[0, 0, 0], [40, 0, 0], [0, 30, 0], [40, 30, 10]], dtype=float)
>>> readings = np.array([1.0, 3.0, 2.0, 5.0])
>>> modulus = pv.FloatAttribute.from_points(sensors, readings, method="rbf")
static inverse_distance_weight(distances: collections.abc.Sequence, index: SupportsInt | SupportsIndex, exponent: SupportsFloat | SupportsIndex = 2.0) → pyvcad.pyvcad.FloatAttribute#

Return the normalized inverse-distance weight of one of several distance fields.

The weight of field i is d_i^-p / sum_j d_j^-p, and the weights of all fields sum to 1 everywhere. Distances below 0 (inside a body) count as 0. Where some distances are 0, those fields share the weight equally (1/k each for k zero distances) and the others get 0. With distances to seed points this is inverse-distance (Shepard) weighting; with distances to bodies it blends between parts. The range is [0, 1].

Parameters:

  • distances (list[FloatAttribute]) – One distance field per seed or body.

  • index (int) – Which field’s weight to return.

  • exponent (float) – The power p, positive. Larger values make each region more uniform.

Raises:

RuntimeError – If distances is empty, index is out of range, or exponent is not positive.

Example

>>> near = [pv.FloatAttribute.distance_to(body, bandwidth=20.0) for body in parts]
>>> weight = pv.FloatAttribute.inverse_distance_weight(near, 0, exponent=2.0)

static surface_angle()#

(body: pyvcad.pyvcad.Node, direction: object = (0.0, 0.0, 1.0), voxel_size: typing.SupportsFloat | typing.SupportsIndex = 0.5, bandwidth: typing.SupportsFloat | typing.SupportsIndex = 10.0, degrees: bool = True) -> pyvcad.pyvcad.FloatAttribute

transfer(self: pyvcad.pyvcad.FloatAttribute, points: object, interpolation: str = 'linear') → pyvcad.pyvcad.FloatAttribute#

Return this attribute mapped through a transfer curve drawn through control points.

Each control point (x, y) maps the input value x to the output y. Between points the curve is a straight line ("linear") or a smooth monotone cubic ("smooth"), which never overshoots: between two points it stays between their values. Below the first and above the last point the curve holds the end values. Use it for any non-linear material law, for example density to stiffness.

Parameters:

  • points (list[tuple[float, float]] | numpy.ndarray) – At least two (x, y) control points with distinct x, in any order; an (N, 2) array works too.

  • interpolation (str) – “linear” or “smooth”.

Example

>>> density = pv.FloatAttribute("x").normalize(0.0, 50.0)
>>> modulus = density.transfer([(0.0, 1.0), (0.4, 2.0), (1.0, 9.0)], interpolation="smooth")

Sampling falls back to value when this attribute raises an error or returns a non-finite number, for example a CellMap coordinate sampled outside the map domain. Valid samples are returned unchanged. Fields: make, change, use#

An attribute is a field: a value at every point. There is one field system, and every tool below is either a way to make a field, an operation that changes one into a new field, or a place that uses one. Each field source has one spelling, a method on FloatAttribute (one number per point) or Vec3Attribute (three numbers per point); the classes below are what those methods return.

  • Make: a constant, an expression string, a numba function, a volume (FloatAttribute(volume)), simulation results (UnstructuredFieldDataset), and FloatAttribute.distance_to(body), .surface_angle(body), .curvature(body), .between(first, second), .noise(...), .from_points(points, values); Vec3Attribute.surface_normal(body), .noise(...), .from_points(points, vectors).

  • Change: + - * /, clamp, normalize, map_range, ease, transfer; Vec3Attribute.dot, .angle, .magnitude, .component. Each returns a new field.

  • Use: grade material with node.set_attribute(name, field) or VolumeFractionsAttribute([(field, material), ...]); drive geometry by passing a field wherever an operator takes a size (offset, shell thickness, blend radius, twist rate) or a vector (Warp, Warp.displace).

  • Convert (a separate, later stage): the converters further down work on named values after a subtree has been sampled and its parts merged, inside an AttributeModifier node, for example modulus to printer volume fractions. Shape fields with the operations above; use converters only for that last step.

Shaping fields#

Every FloatAttribute has methods that return a new, shaped field: arithmetic operators, clamp, normalize, map_range, and two shaping curves. ease clamps a field to [0, 1] and passes it through an easing curve (Easing); transfer maps it through a curve drawn through control points, straight or smooth. The result is an ordinary attribute, so it can grade material (VolumeFractionsAttribute takes fields directly) or drive geometry.

import pyvcad as pv

ramp = pv.FloatAttribute("z").normalize(0.0, 40.0)
soft = ramp.ease("smootherstep")
stiffness = ramp.transfer([(0.0, 1.0), (0.5, 2.0), (1.0, 8.0)], interpolation="smooth")
fractions = pv.VolumeFractionsAttribute([(soft, 1), (1.0 - soft, 2)])

Fields from scattered points#

Values known only at scattered points (measurements, sensor readings, simulation results exported as points) become a field defined everywhere with FloatAttribute.from_points(points, values) or Vec3Attribute.from_points(points, vectors), from NumPy arrays. The points are indexed by a k-d tree. Three methods fill the space between them:

  • "nearest": the value of the nearest point.

  • "idw" (default): a weighted average of the nearest points; exact at the points, continuous, and always within the range of the data, so it can drive geometry without hints.

  • "rbf": a smooth surface through every point. kernel="thin_plate_spline" is global (up to 2,500 points; fitting is a dense solve, about a second for 2,000 points, and each sample visits every point). kernel="wendland" reaches only radius from each point, so it scales to many points; away from the data it returns to the mean value. smoothing fits noisy data loosely.

bounded = pv.FloatAttribute.from_points(sensors, readings, method="idw", neighbors=4)

class pyvcad.LookupTableConverter#

A generic lookup-table-based attribute converter.

Maps input attribute value(s) to output attribute value(s) using a lookup table. Supports STEP (range-based threshold matching) and LINEAR (sorted-point interpolation with clamping) modes.

  • STEP, one input: the first entry whose [input_low, input_high] contains the value wins, and its output_values set the outputs in order. No match leaves the samples unchanged.

  • STEP, several inputs: each input is matched independently against input_ranges. With several outputs, each matched input sets its own output. With one output, the output is written only when every input matched (all-or-nothing), and the values are assembled (Vec3 + float -> Vec4).

  • LINEAR needs exactly one output. With one input, entries are sorted by input_low and interpolated, clamped at the ends. With two inputs, entries give input_points, must form a complete rectilinear grid, and are bilinearly interpolated.

Inputs must be float samples. A missing input leaves the samples unchanged (in multi-input STEP it is skipped). Input samples are kept.

Single-input STEP example (HU to Color):
>>> import pyvcad as pv
>>> entries = [
...     pv.LookupTableEntry(-1000, -500, pv.Vec4(0,0,0,0)),
...     pv.LookupTableEntry(-500, 0, pv.Vec4(1,0,0,0.5)),
... ]
>>> conv = pv.LookupTableConverter(['hu'], ['color_rgba'], entries, pv.InterpolationMode.STEP)
Multi-input STEP example (temperature -> RGB, density -> alpha):
>>> entries = [
...     pv.LookupTableEntry([(0, 1), (0, 0.01)], [pv.Vec3(1,1,1), 0.0]),
...     pv.LookupTableEntry([(1, 10), (0.01, 0.5)], [pv.Vec3(1,0,0), 0.5]),
... ]
>>> conv = pv.LookupTableConverter(
...     ['temperature', 'density'], ['color_rgba'],
...     entries, pv.InterpolationMode.STEP)
Two-input LINEAR example (modulus+toughness to volume fractions):
>>> entry = pv.LookupTableEntry([10.0, 2.0], {1: 0.7, 2: 0.2, 3: 0.1})
>>> entry.is_valid = True
>>> conv = pv.LookupTableConverter(
...     ['modulus', 'toughness'], ['volume_fractions'],
...     [entry], pv.InterpolationMode.LINEAR)
LINEAR example (temperature to flow rate):
>>> entries = [pv.LookupTableEntry(180, 1.0), pv.LookupTableEntry(220, 0.5)]
>>> conv = pv.LookupTableConverter(['temperature'], ['flow_rate'], entries, pv.InterpolationMode.LINEAR)

class pyvcad.ExpressionConverter#

An attribute converter that evaluates mathematical expressions.

Input attribute names are used directly as variable names in the expression strings. For example, if input_attributes = [‘temperature’], then the expression ‘20 * temperature + 100’ will read the ‘temperature’ attribute sample and compute the result.

Each output attribute has its own expression string.

Inputs must be scalar (float) samples. If any input is missing at a point, the samples pass through unchanged. Otherwise each output is added or replaced and the inputs are kept. Expressions are compiled on the first convert() call, so a bad expression raises there rather than in the constructor.

Example (single output):
>>> import pyvcad as pv
>>> conv = pv.ExpressionConverter(
...     input_attributes=['temperature'],
...     output_attributes=['flow_rate'],
...     expressions=['20 * temperature + 100'])
Example (multiple outputs):
>>> conv = pv.ExpressionConverter(
...     input_attributes=['hu'],
...     output_attributes=['modulus', 'toughness'],
...     expressions=['hu * 1000 + 500', '0.5 * hu + 10'])
