Curves and Profiles#

Parametric curves in 3D, with planar curves as a special case, and the frames that carry a profile along them. Points can be passed as tuples, lists, Vec3, Vec2, Point2 or NumPy arrays; batched results come back as NumPy arrays. Curves never change after construction, so one curve can be shared by many nodes.

Curves#

class pyvcad.Curve#

Base class of all curves: an immutable parametric curve in 3D.

A curve maps a parameter t in domain to a point. Planar curves are the case where every point lies in one plane; 2D input is placed at z = 0. Points can be passed as tuples, lists, Vec3, Vec2, Point2, or NumPy arrays; batched results are NumPy arrays.

Accuracy: closest points are exact closed forms for LineSegment, PolylineCurve and ArcCurve. For other curves they come from a box-pruned search refined with Newton’s method, exact to about 1e-12 relative. Near the centre of curvature of a curved piece the search can settle on a local minimum; the distance is then within twice the piece’s deviation from its chord of the true minimum (for BezierCurve and BSplineCurve, at most 1e-5 of the control-point box diagonal per piece). Arc lengths use Gauss-Legendre quadrature.

Example

>>> import pyvcad as pv
>>> curve = pv.BSplineCurve.interpolate([(0, 0), (10, 5), (20, 0)])
>>> hit = curve.closest_point((10, 0, 0))

class pyvcad.ArcCurve#

A circular arc or full circle, with t in [0, 1]. Exact.

Angles are in degrees, measured in the arc’s plane from world +X projected into the plane (world +Y when the normal is along X), counter-clockwise about the normal. Frames#

class pyvcad.CurveFrames#

Rotation-minimizing frames along a curve.

The frames turn as little as possible about the tangent, so a profile carried along the curve does not twist on its own (double-reflection method). On a closed curve the leftover rotation after one loop (the holonomy) is spread evenly in arc length, so the frames match at the seam.

Profiles#

class pyvcad.Profile#

An immutable closed region of the XY plane, bounded by closed curves, possibly with holes.

A profile is the cross-section that Extrude, Revolve and Sweep turn into solids. Loops may be any closed curve at z = 0 and must not cross themselves or each other. Nesting decides what is inside: a loop inside an even number of other loops is an outline, otherwise a hole.

Signed distance is exact, computed from the curves (negative inside). Booleans (|, &, -) run on tessellations for robust topology and then rebuild the result from pieces of the input curves, so arcs and splines stay exact. Round offsets of profiles made of straight edges and arcs are exact; other offsets are polygons within tolerance (default min(0.001, 1e-4 x size)). fillet() rounds corners with exact arcs.

Example

>>> import pyvcad as pv
>>> plate = pv.Profile.rounded_rectangle(40, 20, 3) - pv.Profile.circle(4, center=(10, 0))
>>> plate.area()

class pyvcad.Sketch#

Draw 2D profiles and paths step by step, like a pen: lines, arcs and splines from the current point, with optional fillets and chamfers at the corners.

Each drawing method adds a piece from the pen position and moves the pen to its end, so a path has no gaps. The sketch tracks the current direction (the end tangent of the last piece), which tangent_arc_to() and tangent_arc() continue without a kink. Drawing methods take fillet= or chamfer= to treat the corner at the piece’s end; close() takes them for the corner where the loop closes. Fillets and chamfers work between lines and arcs (not next to Bezier or spline pieces).

close() finishes a loop and move_to() starts a new path: a loop drawn inside another becomes a hole. profile() builds a Profile from the closed loops; curves() and curve() return paths as curves (for example to sweep along). Every drawing method returns the sketch, so calls chain.

Example

>>> import pyvcad as pv
>>> s = pv.Sketch((0, 0))
>>> s.line_to(40, 0).tangent_arc_to(40, 20).line_to(0, 20, fillet=4).close(chamfer=2)
>>> plate = s.profile()

class pyvcad.Plane#

A plane to draw a profile on: an origin and right-handed in-plane axes.

A profile’s (x, y) lands at origin + x * x_axis + y * y_axis, and normal = x_axis x y_axis points out of the plane. Extrude and Loft build along the normal; Revolve spins about the plane’s y axis through its origin, so a profile’s x is its distance from that axis.

The standard planes: Plane.xy(z) (x along +X, y along +Y, normal +Z), Plane.xz(y) (x along +X, y along +Z, normal -Y) and Plane.yz(x) (x along +Y, y along +Z, normal +X). Placing a profile with a plane is rigid, so distances stay exact.

Example

>>> import pyvcad as pv
>>> side = pv.Plane.xz()
>>> rib = pv.Extrude(pv.Profile.rectangle(20, 8, center=(0, 4)), 2.0, symmetric=True, plane=side)

Closed-form intersections, tangents and corner treatments. Lines are infinite lines through two points and circles are a centre and a radius; every function returns all of its solutions, in a stated order, as NumPy arrays.

The intersection point, or an empty list for parallel lines.

The lines touching two circles, as pairs of tangent points.

The outer tangents (both circles on the same side of the line) come first, then the inner ones (crossing between the circles). (point on circle 0, point on circle 1) for each line.

Curves from data#

Mesh paths (MeshPath.to_curve()), mesh and selection borders (SurfaceMesh.boundary_loops(), MeshSelection.boundary_loops()) and node contours all return ordinary curves. Profile.cross_section() gives the region of a slice instead of its outlines.

pyvcad.contour_curves(node: pyvcad.pyvcad.Node, z: SupportsFloat | SupportsIndex, voxel_size: SupportsFloat | SupportsIndex, iso: SupportsFloat | SupportsIndex = 0.0) → list[pyvcad.pyvcad.Curve]#

Trace the iso-lines of a node on the plane at height z, as curves at that height.

Marching squares on a clone of the node prepared at voxel_size, which is also the cell size. Closed contours come first (closed PolylineCurves, counter-clockwise), then open ones. Accurate to about voxel_size. Use Profile.cross_section() for the region instead of its outlines.

Parameters:

  • node (Node) – The node.

  • z (float) – Height of the plane.

  • voxel_size (float) – Sampling resolution in mm (the marching-squares cell size).

  • iso (float) – The level to trace; 0 is the surface, positive values trace outside it.

Example

>>> import pyvcad as pv
>>> outlines = pv.contour_curves(part, 5.0, 0.1)
>>> rims = pv.Union([pv.Tube(c, 0.5) for c in outlines])
