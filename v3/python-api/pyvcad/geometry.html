Geometry#

2D and 3D geometry types that the tree nodes are built on. Some are inputs you build directly: vectors and polygons, meshes and CAD models, height fields for surface relief, the CellMap that bends a lattice to a part, unit cells, and seed points with their surface Voronoi diagrams. Others are helpers for custom geometry and analysis, such as hexahedral and tetrahedral meshing.

class pyvcad.Polygon2#

A 2D polygon with exact (CGAL) coordinates and an optional list of holes.

The vertices are the outer boundary, stored without repeating the first point. Holes are kept as a separate list of Polygon2. Iterating a Polygon2 yields the outer boundary’s Point2 values. Most queries (is_ccw, inside, on_boundary, bounding_box, double_area, simplify) look only at the outer boundary; the booleans, offset and clip also use the holes.

The boolean operations use Clipper2 with the even-odd fill rule, so polygons that overlap inside one operand list cancel (XOR) there. They return one Polygon2 per output contour: outer contours are counter-clockwise, and holes come back as separate clockwise polygons with no holes() of their own.

Example

>>> import pyvcad as pv
>>> square = pv.Polygon2([pv.Vec2(0, 0), pv.Vec2(2, 0), pv.Vec2(2, 2), pv.Vec2(0, 2)])
>>> square.double_area()
4.0

class pyvcad.Arrangement2#

A 2D arrangement of line segments.

Inserted polygons and polylines are split at every crossing, and the plane is divided into faces. There is exactly one unbounded face (everything outside the inserted geometry); all other faces are bounded.

>>> arrangement = pv.Arrangement2()
>>> arrangement.insert(pv.Polygon2([pv.Vec2(0, 0), pv.Vec2(2, 0), pv.Vec2(2, 2), pv.Vec2(0, 2)]))
>>> arrangement.insert(pv.Polyline2([pv.Vec2(1, -1), pv.Vec2(1, 3)]))
>>> len(arrangement.getBoundedFaces())
2

class pyvcad.TriangleMeshSurface#

An immutable triangle-mesh disk patch flattened into a UV chart so it can drive a CellMap like a CAD face. The patch may contain holes (vents): the longest boundary loop is the outer edge and every other loop is filled internally for flattening and then treated as trimmed. The flattening method is selectable: ‘lscm’ (default, free-boundary near-conformal), ‘arap’ (free-boundary as-rigid-as-possible), or ‘authalic’ (circular-border iterative area-preserving). Free-boundary charts keep the patch’s natural outline inside their UV bounding rectangle; contains() reports the real boundary so CellMap trimming stops the lattice at the patch edge. If the requested map folds, a guaranteed-injective convex-border mean-value parameterization is used instead.

static warp(base: pyvcad.pyvcad.CellMap, u_scale: object = None, v_scale: object = None, w_scale: object = None, lock_u_bounds: bool = True, lock_v_bounds: bool = True, lock_w_bounds: bool = True) → pyvcad.pyvcad.CellMap#

Return a new map with the same cells but a graded cell spacing along U, V, and/or W.

Along each axis, every element’s logical width is weighted by exp(clamp(s, -4, 4)), where s is the scale attribute sampled at the element’s midpoint on the base map. The scale is a natural-log exponent, not a relative weight: 0 (or None) keeps the spacing uniform, +1 makes a cell about 2.7 times wider than a cell at 0, and -1 about 2.7 times narrower. The attribute is sampled with the base map’s unwarped world position as x, y, z, and with the base map’s logical and cell coordinates available for cell-map attributes. It must return a finite scalar.

With a locked axis, the weights are normalized so the axis still spans its full logical range and both opposite boundaries stay where they are; only the distribution of cells changes. With an unlocked axis, each cell’s width is multiplied by its weight, so the far boundary moves (the map is continued linearly past the base map’s end) while the logical-0 boundary stays fixed.

The requested spacing is smoothed. If the result folds the map (fails validate()), the warp is blended back toward the base map, halving its strength each time, until the map is valid.

Maps clipped by a boundary trim (has_boundary_trim is True) cannot be warped. TrimMode.boundary is the default for the surface factories, so build the base map with trim=TrimMode.none or TrimMode.cells before warping.

Parameters:

  • base (CellMap) – Base map.

  • u_scale (FloatAttribute | float | None) – Log-scale exponent for U cell widths. None means 0.

  • v_scale (FloatAttribute | float | None) – Log-scale exponent for V cell widths. None means 0.

  • w_scale (FloatAttribute | float | None) – Log-scale exponent for W cell widths. None means 0.

  • lock_u_bounds (bool) – Keep both U boundaries fixed and only redistribute the cells.

  • lock_v_bounds (bool) – Keep both V boundaries fixed and only redistribute the cells.

  • lock_w_bounds (bool) – Keep both W boundaries fixed and only redistribute the cells.

Returns:

The warped map, with the base map’s cells, periodicity, active elements, and trim mode.

Return type:

CellMap

Raises:

  • TypeError – If a scale is not a FloatAttribute, a number, or None.

  • RuntimeError – If the base map has a boundary trim, a scale attribute returns a non-finite or non-scalar value, or the warp still folds the map after being scaled down to 1e-4 strength.

Example

>>> import pyvcad as pv
>>> cell_map = pv.CellMap.rectangular(pv.Vec3(0, 0, 0), pv.Vec3(10, 10, 10), (5, 5, 5))
>>> # Cells grow along x: narrow near x = 0, wide near x = 10.
>>> warped = pv.CellMap.warp(cell_map, u_scale=pv.FloatAttribute("x / 10"))
