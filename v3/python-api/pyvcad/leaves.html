Tree — leaf nodes#

Leaves are terminal Node subclasses: they do not wrap other nodes as children. They are where concrete implicit geometry and sources live—analytic primitives, meshes, CAD imports, lattices, extruded profiles, and signed-distance fields.

The enums documented next to a node configure that node. Classes that are not nodes themselves, such as the beams and balls of a BeamLattice, the 3MF import helpers, and the component and provenance records of the mapped and stochastic lattices, are grouped at the end under Supporting types (not nodes).

Nodes that combine or transform subtrees are composition operators; see Tree — composition nodes.

Constructor that takes a callable to evaluate and a bounding box.

The callable must return the signed distance to the surface for a given point. Two kinds of callable are accepted:

  • A numba.cfunc with signature float64(float64, float64, float64) -> (x, y, z). This is dispatched through the native function pointer and is the fast path.

  • A plain Python callable taking eight floats (x, y, z, rho, phic, r, theta, phis). This is supported for convenience but is slow (a Python call per evaluation).

Parameters:

  • function (callable) – The signed-distance callable (numba.cfunc preferred).

  • min (Vec3) – The minimum bounding box coordinates. Defaults to (-10, -10, -10).

  • max (Vec3) – The maximum bounding box coordinates. Defaults to (10, 10, 10).

Example

>>> from numba import cfunc, types
>>> import math
>>> import pyvcad as pv
>>> @cfunc(types.float64(types.float64, types.float64, types.float64))
... def gyroid(x, y, z):
...     f = 2.0 * math.pi / 10.0
...     return (math.sin(f*x)*math.cos(f*y) + math.sin(f*y)*math.cos(f*z)
...             + math.sin(f*z)*math.cos(f*x))
>>> node = pv.Function(gyroid, pv.Vec3(-15, -15, -15), pv.Vec3(15, 15, 15))

class pyvcad.MappedGraphLattice#

A compact graph unit cell tiled and curved through a CellMap.

Struts and joints are combined sharply unless member_blend_radius is given; then distinct struts and joints are joined with the shared smooth blend, which fillets the nodes. Copies of a strut or joint shared by neighbouring cells count as one member and never bulge. Fillet material takes the nearest member’s attributes.

Distance accuracy: always approximate. Where no map cell is found the value is the distance to the map domain rather than to the struts, and tapered pieces use a bounded nearest-point search.

class pyvcad.Tube#

class pyvcad.Extrude#

A profile extruded from a sketch plane along its normal, with optional draft (taper), twist and a wall offset law.

The profile lies in plane (the XY plane by default) and is extruded along the plane’s normal from 0 to height (the other way for a negative height), or symmetrically about the plane. Draft tapers the walls: the section at distance s from the profile plane is the profile shrunk by s * tan(draft) (a negative draft widens it). Twist turns the section counter-clockwise about the normal, from 0 at the profile plane to twist degrees at the far end. The offset law shapes the walls along the height: points (f, w) grow the section by w (shrink it for negative w) at fraction f of the way from the profile plane to the far end (from bottom to top when symmetric), joined smoothly between the points.

Attributes: the node’s own, plus coordinate fields from coordinate_field(): ‘u’ and ‘v’ (section coordinates with the twist undone), ‘height’ (above the bottom face), ‘normalized_height’ (0 to 1) and ‘profile_distance’ (signed distance to the section outline).

Distance accuracy (distance_accuracy()): exact without draft, twist or offset law; an approximation with any of them (just outside the part the value drops below the distance to its bounding box).

class pyvcad.Sweep#

A profile swept along a path curve.

The profile’s (u, v) plane is carried along the path in its rotation-minimizing frames (u along the frame normal, v along the binormal), so it does not twist on its own. For a planar path v follows the plane normal unless up says otherwise. scale and twist (degrees, counter-clockwise about the path tangent) may be numbers or fields sampled at the closest path point, so a law along the path is a field built from the path’s own fields, e.g. path.length_field(normalized=True). twist is the section’s angle at each point, not a total as in Extrude: a constant turns the whole section by that angle, and path.length_field(normalized=True) * 180 twists it half a turn from end to end. pyvcad.read_3mf_beam_lattice(path: str) → pyvcad.pyvcad.ThreeMFBeamLatticeScene#

Reads the geometry of a 3MF file, including any beam lattices, without building a tree.

Every build item is resolved through its component graph, transforms are baked into the returned coordinates, and coordinates are converted to millimeters. Beam and ball property references are not read; this importer covers geometry only.

Parameters:

path (str) – The path to the .3mf file.

Example

>>> len(scene.objects[0].beams)
