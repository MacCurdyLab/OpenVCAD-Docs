Tree — base classes#

These types form the structural vocabulary of the OpenVCAD graph. Every design is a Node tree: the engine evaluates signed distance and attributes by walking from the root to the leaves and aggregating results upward.

Leaf marks terminals that hold geometry or field data directly (see Tree — leaf nodes). Most other nodes are composition operators; they wrap one or more child subtrees and are modeled as Unary, Binary, or NAry according to how many children they take (see Tree — composition nodes).

class pyvcad.Node#

Base class for all nodes in the tree. NOTE: the VCAD tree is NOT thread-safe. You must use a separate tree for each thread (see Node.clone()).

distance_accuracy(self: pyvcad.pyvcad.Node) → pyvcad.pyvcad.DistanceAccuracy#

How faithfully this node’s value, including its whole subtree, matches the true signed distance.

exact: a true signed distance. bound: within the bandwidth, the value never exceeds lipschitz_bound() times the true distance, so a positive value v proves no material lies within v / lipschitz_bound(). approximate: no guarantee away from the surface. Only valid after prepare().

Returns:

The accuracy of the subtree rooted at this node.

Return type:

DistanceAccuracy

volume(*args, **kwargs)#

Overloaded function.

  1. volume(self: pyvcad.pyvcad.Node) -> float

Estimates the node volume by sampling the signed distance field over its bounding box.

The sample size is automatically computed from the bounding box as the longest dimension divided by 128. Returns cubic model units, e.g. mm^3 when the model is authored in millimeters. This counts inside voxels; pv.mass_properties() weights voxels cut by the surface, is far more accurate, and also gives surface area, mass and inertia.

Parameters:

Inspecting a tree#

SubtreeView isolates one node of a design so it can be sampled or rendered on its own, optionally with its placement and inherited attributes re-applied. TreeDiagram turns a tree into a Mermaid flowchart.

class pyvcad.SubtreeView#

A read-only view of one node of a design, with optional ancestor context re-applied.

With no context the view is exactly the target node’s own result in its own coordinate frame, so every operation above it is undone. apply_placement re-applies Translate/Rotate/Scale/Transform/Mirror ancestors; apply_attributes re-applies ancestor attributes and AttributeModifier/Blend/Convolve ancestors. Booleans and shape modifiers above the target are never applied. The view shares the design’s nodes, so do not prepare a view and its design at the same time from different threads.

applies_attributes(self: pyvcad.pyvcad.SubtreeView) → bool#

Returns True if ancestor attributes are re-applied.

applies_placement(self: pyvcad.pyvcad.SubtreeView) → bool#

Returns True if ancestor placement is re-applied.

static build(path: collections.abc.Sequence[pyvcad.pyvcad.Node], apply_placement: bool = False, apply_attributes: bool = False) → pyvcad.pyvcad.SubtreeView#

Builds a view of the last node of a root-to-target path.

Parameters:

  • path (list[Node]) – The nodes from the root (first) to the target (last). Each must be a child of the previous one.

  • apply_placement (bool) – Re-apply placement ancestors so the target sits where it lands in the full design.

  • apply_attributes (bool) – Re-apply ancestor attributes and attribute-process ancestors.

Example

>>> import pyvcad as pv
>>> sphere = pv.Sphere(pv.Vec3(0, 0, 0), 5)
>>> root = pv.Translate(10, 0, 0, sphere)
>>> view = pv.SubtreeView.build([root, sphere], apply_placement=True, apply_attributes=False)
