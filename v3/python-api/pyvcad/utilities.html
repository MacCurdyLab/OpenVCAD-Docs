class pyvcad.ColorMap#

A piecewise-linear color map over [0, 1].

Colors are RGB Vec3s with channels in [0, 1], placed at stop values. get_color() clamps its input to [0, 1] and interpolates linearly between the two nearest stops.

Example

>>> import pyvcad as pv
>>> cmap = pv.ColorMap()
>>> cmap.add_color(0.0, pv.Vec3(0, 0, 1))
>>> cmap.add_color(1.0, pv.Vec3(1, 0, 0))
>>> purple = cmap.get_color(0.5)

as_narrow_band_signed_distance_array(self: pyvcad.pyvcad.TreeSampler, progress: object = None, band_voxels: SupportsFloat | SupportsIndex = 3.0, coarse_factor: SupportsInt | SupportsIndex = 4) → numpy.ndarray#

Sample the signed distance field on the as_signed_distance_array() grid, evaluating the design exactly only near its surface.

Voxels within band_voxels voxels of the surface hold exactly the values as_signed_distance_array() would; farther voxels keep the correct sign but not the exact distance. Contouring at 0 gives the same surface much faster when the design’s bounding box is mostly empty (shells, lattices on curved parts, separate bodies). Use as_signed_distance_array() when values far from the surface matter.

Parameters:

  • progress (callable, optional) – Progress callback taking an int 0-100.

  • band_voxels (float) – Half-width of the exact band, in voxels. Defaults to 3.

  • coarse_factor (int) – Coarse probe cell size, in voxels (>= 2). Defaults to 4.

Returns:

float32 array of shape (nx*ny*nz,), same layout as as_signed_distance_array().

Return type:

numpy.ndarray

culling_stats(self: pyvcad.pyvcad.TreeSampler) → CullingStats#

Counts from the last sampling pass that could skip voxels.

Set by the voxel-grid pass behind as_rgba_array(), as_float_array(), as_vec3_array(), as_vec4_array() and as_material_fraction_array(), and by save_openvdb_occupancy_grid(): these skip voxels the tree’s distance bound proves hold no material. Also set by as_narrow_band_signed_distance_array(), which skips voxels proven to lie beyond its band (sampled_voxels then counts voxels evaluated exactly). Outputs are the same as sampling every voxel. Results served from a cache leave the counts unchanged; before any such pass they are empty. Culling falls back to every voxel for an approximate tree, a tree without a finite Lipschitz bound, or with OPENVCAD_DISABLE_CULLING=1 (see fallback_reason).

Returns:

The counts of that pass.

Return type:

CullingStats

class pyvcad.CullingStats#

Counts from a sampling pass that skipped voxels proven empty.

A voxel is skipped only when the tree’s distance bound proves it holds no material, so the output is identical to sampling every voxel. Culling falls back to sampling everything when the tree’s distance_accuracy() is approximate, its lipschitz_bound() is not finite, or it is switched off (set_culling_enabled(False) on a compiler, or the environment variable OPENVCAD_DISABLE_CULLING=1).

property accuracy#

The root’s distance_accuracy().

property active#

True if culling ran; False if every voxel was sampled.

property bandwidth#

The bandwidth the root was prepared with.

property fallback_reason#

Why culling did not run (empty when active).

property lipschitz#

The root’s lipschitz_bound().

property probes#

evaluate() calls spent on the proofs.

property sampled_voxels#

Voxels sampled (one sample() call each).

skipped_fraction(self: pyvcad.pyvcad.CullingStats) → float#

Fraction of voxels skipped.

property skipped_voxels#

Voxels proven empty without a sample() call.

property total_voxels#

Voxels in the layers built so far (the whole grid once a pass has finished).

pyvcad.probe_point(node: pyvcad.pyvcad.Node, point: pyvcad.pyvcad.Vec3, tolerance: SupportsFloat | SupportsIndex = 0.0001, max_iterations: SupportsInt | SupportsIndex = 16) → pyvcad.pyvcad.SurfaceProbeResult#

Projects a point onto the nearest surface of a prepared tree and reports the normal there.

The starting point may be inside, outside, or already on the surface; it is walked down the signed distance field until it lands on the surface. This is the query behind the renderer’s Probe tool: pick a point on screen, then ask what the surface is doing there.

Parameters:

  • node (Node) – The prepared node to interrogate. Call prepare() first.

  • point (Vec3) – The starting point in world coordinates.

  • tolerance (float, optional) – The signed distance that counts as on the surface. Defaults to 1e-4.

  • max_iterations (int, optional) – The maximum number of steps to take. Defaults to 16.

Returns:

The surface position, unit normal, and residual signed distance.

Return type:

SurfaceProbeResult

Example

>>> import pyvcad as pv
>>> sphere = pv.Sphere(pv.Vec3(0, 0, 0), 10.0)
>>> sphere.prepare(pv.Vec3(0.2, 0.2, 0.2), 1.0)
>>> probe = pv.probe_point(sphere, pv.Vec3(8.0, 0.0, 0.0))
>>> print(probe.position.x, probe.normal.x)
10.0 1.0
pyvcad.probe_ray(node: pyvcad.pyvcad.Node, origin: pyvcad.pyvcad.Vec3, direction: pyvcad.pyvcad.Vec3, step_size: SupportsFloat | SupportsIndex = 0.0, tolerance: SupportsFloat | SupportsIndex = 0.0001) → pyvcad.pyvcad.SurfaceProbeResult#

Casts a ray at a prepared tree and reports the first surface it enters.

The ray is clipped to the node’s bounding box, marched until it crosses into the solid, and then refined onto the surface. This is the query a viewport pick maps onto, with the camera position as the origin and the unprojected click as the direction.

Parameters:

  • node (Node) – The prepared node to interrogate. Call prepare() first.

  • origin (Vec3) – The ray origin in world coordinates.

  • direction (Vec3) – The ray direction. Need not be normalized, but must not be zero length.

  • step_size (float, optional) – The march step in mm. Pass 0 to derive one from the bounding box.

  • tolerance (float, optional) – The signed distance that counts as on the surface. Defaults to 1e-4.

Returns:

The entry point, unit normal, and residual signed distance. hit is False when the ray misses the node.

Return type:

SurfaceProbeResult

Example

pyvcad.surface_normal(node: pyvcad.pyvcad.Node, point: pyvcad.pyvcad.Vec3) → pyvcad.pyvcad.Vec3#

Returns the outward unit surface normal of a prepared tree at a point.

This is the normalized signed distance gradient. Away from the surface it is the direction of steepest increase of the field. Returns a zero vector when the gradient is degenerate.

Parameters:

  • node (Node) – The prepared node to interrogate. Call prepare() first.

  • point (Vec3) – The point to evaluate, in world coordinates.

Returns:

The outward unit normal.

Return type:

Vec3

Example

>>> import pyvcad as pv
>>> sphere = pv.Sphere(pv.Vec3(0, 0, 0), 10.0)
>>> sphere.prepare(pv.Vec3(0.2, 0.2, 0.2), 1.0)
>>> normal = pv.surface_normal(sphere, pv.Vec3(0.0, 10.0, 0.0))
>>> print(normal.y)
1.0
pyvcad.alignment_angles(forward: pyvcad.pyvcad.Vec3, up: pyvcad.pyvcad.Vec3 = <pyvcad.pyvcad.Vec3 object at 0x10e59e1b0>) → pyvcad.pyvcad.Vec3#

Computes the Rotate angles that aim a child node’s local axes along a chosen frame.

The child’s local +Z is aimed along forward and its local +Y along up. up only has to be roughly right: it is orthogonalized against forward, and a world axis is substituted when the two are parallel.

The Text node extrudes along +Z, so passing a surface normal as forward stands text up off that surface. Text builds its glyphs on a flipped X axis, which puts their visual up along its own -Y, so pass the negated world up to get text that reads upright.

Parameters:

  • forward (Vec3) – The world direction the child’s local +Z should point along.

  • up (Vec3, optional) – The world direction the child’s local +Y should point along. Defaults to world +Z.

Returns:

Euler angles in degrees, packed as (pitch, yaw, roll) for the Rotate node.

Return type:

Vec3

Example

>>> import pyvcad as pv
>>> probe = pv.probe_point(sphere, pv.Vec3(8.0, 0.0, 0.0))
>>> angles = pv.alignment_angles(probe.normal, pv.Vec3(0, 0, -1))
>>> facing_text = pv.Rotate(angles, text)
