Compilers#

class pyvcad_compilers.CompilerBase#

Abstract base class of every compiler in pyvcad_compilers.

A compiler stores a design root and its settings when constructed, and does all of its work in compile(), which prepares the root itself. The base class provides progress and status callbacks, cancellation, culling switches and export statistics. Instantiate a concrete compiler such as MaterialInkjetCompiler or VdbCompiler.

cancel(self: pyvcad_compilers.pyvcad_compilers.CompilerBase) → None#

Asks a running compile() to stop. compile() then raises RuntimeError(‘Cancelled’).

Safe to call from another thread.

compile(self: pyvcad_compilers.pyvcad_compilers.CompilerBase) → None#

Compiles the design and writes the output.

Prepares the root, samples it and writes the compiler’s output. Releases the GIL while it runs.

Raises:

RuntimeError – On invalid input, missing required attributes, or after cancel().

culling_enabled(self: pyvcad_compilers.pyvcad_compilers.CompilerBase) → bool#

Returns True unless set_culling_enabled(False) was called.

culling_stats(self: pyvcad_compilers.pyvcad_compilers.CompilerBase) → pyvcad.pyvcad.CullingStats#

Returns the culling counts (a pyvcad.CullingStats) from the most recent compile.

Inactive, with a fallback_reason, when the design’s distance is approximate, culling is switched off, or the compiler does not cull.

report_stats(self: pyvcad_compilers.pyvcad_compilers.CompilerBase) → None#

Prints export statistics for the most recent successful compile.

Raises:

RuntimeError – If no compile() has finished.

set_culling_enabled(self: pyvcad_compilers.pyvcad_compilers.CompilerBase, enabled: bool) → None#

Switches skipping of voxels proven empty on or off (on by default).

Culling never changes the output; turning it off is for A/B tests and debugging. The environment variable OPENVCAD_DISABLE_CULLING=1 also turns it off.

Parameters:

enabled (bool) – False to sample every voxel.

set_progress_callback(self: pyvcad_compilers.pyvcad_compilers.CompilerBase, arg0: collections.abc.Callable[[float], None]) → None#

Sets the progress callback function.

The callback receives the progress fraction in [0, 1]. Calls are rate-limited to roughly every 1% or 100 ms, but a report of 1.0 is always forwarded. Most compilers report 1.0 at the end of a successful compile; a cancelled or failed compile stops early. Use compile() returning, not a 1.0 report, as the completion signal.

Parameters:

progress_callback (function) – Called with one float argument, the progress.

set_status_callback(self: pyvcad_compilers.pyvcad_compilers.CompilerBase, arg0: collections.abc.Callable[[str], None]) → None#

Sets the compiler stage-status callback.

Parameters:

status_callback (function) – Receives a human-readable compiler stage message.

supported_attributes(self: pyvcad_compilers.pyvcad_compilers.CompilerBase) → list[str]#

Returns the attribute names this compiler works with.

The meaning depends on the compiler. MaterialInkjetCompiler, ColorInkjetCompiler, MyersonCompiler and SimulationCompiler (its direct_attributes) require the root to carry every listed attribute; compile() raises RuntimeError otherwise. VatCompiler and MultiMaterialVatCompiler list the attribute they sample. The slicer project compilers list every attribute they understand; a design may carry any subset. VdbCompiler and GCVFCompiler return an empty list.

Returns:

Attribute names, possibly empty.

Return type:

list[str]

Inkjet and PolyJet#

class pyvcad_compilers.MaterialInkjetCompiler#

Compiles VOLUME_FRACTIONS into material-coded PolyJet slice images.

Each inside voxel is assigned one material and drawn in that material’s MaterialDefs color. Each layer is written as an RGBA PNG named <file_prefix><z>.png in output_directory; empty leading and trailing layers are removed and the rest renumbered from 0.

Constructor. Creates a MaterialInkjetCompiler object.

  • voxel_size (Vec3) – The voxel size in mm (can be anisotropic).

  • file_prefix (str) – File name prefix. Slice z is written as <file_prefix><z>.png.

class pyvcad_compilers.GCVFCompiler#

Compiles a design into a legacy Stratasys GCVF archive for the J750.

Slices the design with MaterialInkjetCompiler (VOLUME_FRACTIONS) or ColorInkjetCompiler (COLOR_RGBA), then packages the PNG stack, a z-buffer image, an STL mesh, bounding-box metadata and ConfigFile.xml into one .gcvf zip archive.

class pyvcad_compilers.MultiMaterialVatCompiler#

Compile volume fractions into synchronized grayscale PNG stacks for dual- or quad-vat printers.

Each inside sample draws one material from its volume fractions with a seeded random draw. Void (material ID 0) takes part in the draw, so a draw that lands on void, or all-zero fractions, leaves the pixel black in every vat. Otherwise the drawn material’s vat gets the pixel, exposed by the optional ‘<material_name>_intensity’ scalar attribute (default 1.0), and the other vats get black. Every non-void material with a positive fraction must be assigned to a vat, or compile() raises RuntimeError. Images use a fixed 1280 x 800 canvas spanning 55.01 x 34.38 mm, with the design centered in XY.

class pyvcad_compilers.PrusaSlicerProjectCompiler#

Compiles slicer attributes into a PrusaSlicer-compatible .3mf project.

Three workflows, picked from the design’s attributes: settings meshes (per-region PrusaSlicer settings such as infill_density), virtual extrusion (temperature with a flow_rate companion, written as toolchange G-code), and ColorMix (COLOR_RGB or VOLUME_FRACTIONS as mixed-filament regions). ColorMix cannot be combined with the other two.

  • num_regions (int) – The number of sub-ranges per attribute dimension. Defaults to 10.

  • filament_profile_path (str) – Path to PrusaSlicer filament profile (.ini). Required when virtual extrusion attributes are present. Defaults to “”.

  • close_unresolved_band_gaps (bool) – Closes the sub-voxel slot left where a segmented attribute jumps by more than one region between neighbouring voxels (e.g. a discontinuous attribute, or a gradient too steep for the voxel size). Off leaves the legacy behaviour.

>>> compiler.compile()
