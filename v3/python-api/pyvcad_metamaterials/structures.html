TPMS, strut, and face lattices#

TPMS lattices#

Every TPMS builder returns a pyvcad.MappedImplicitLattice (or a pyvcad.MappedStructureCollection for a multi-map collection) in either "sheet" or "solid" mode.

pyvcad_metamaterials.tpms(cell_map, kind, mode='sheet', wall_thickness=1.0, level=0.0)[source]#

Evaluate a standard or custom periodic implicit unit cell in a CellMap.

The unit cell repeats once per map cell, so the cell size comes from cell_map. The cell’s scalar field is converted to an approximate signed distance in world millimetres through the map Jacobian, so wall thickness and level stay physical lengths on stretched or curved maps.

Parameters:

  • cell_map (pv.CellMap | pv.CellMapCollection) – Map that places the cells, e.g. from rectangular_cell_map().

  • kind (str | pv.ImplicitUnitCell) – A name from TPMS_NAMES ("gyroid", "schwarz_p", …) or a custom pv.ImplicitUnitCell.

  • mode (str) – "sheet" (default) builds a wall of wall_thickness centred on the mid-surface. "solid" fills one side of the mid-surface, offset by level.

  • wall_thickness (float | pv.FloatAttribute | callable) – Total sheet wall thickness in mm, default 1.0. Must stay positive. Used only in "sheet" mode.

  • level (float | pv.FloatAttribute | callable) – Solid level offset in mm, default 0.0. The solid is where the signed distance to the mid-surface is below level, so a positive value grows it. Used only in "solid" mode.

Controls accept a number, a pv.FloatAttribute field sampled at each point (plain x, y, z are in mm; cell_map.logical_position and friends give cell coordinates), or a Python function f(x, y, z, d) that is compiled with numba.cfunc.

Returns:

a pv.MappedImplicitLattice for one map, or a pv.MappedStructureCollection when cell_map is a pv.CellMapCollection holding more than one map.

Return type:

pv.Node

Raises:

TypeError – If kind is neither a name nor a pv.ImplicitUnitCell.

Example

>>> node = mm.tpms(cell_map, "schwarz_p", wall_thickness=1.0)
pyvcad_metamaterials.TPMS_NAMES#

Built-in immutable sequence.

If no argument is given, the constructor returns an empty tuple. If iterable is specified the tuple is initialized from iterable’s items.

If the argument is a tuple, the return value is the same object.

Strut (graph) lattices#

Every strut builder returns a pyvcad.MappedGraphLattice (or a pyvcad.MappedStructureCollection for a multi-map collection).

pyvcad_metamaterials.graph_lattice(cell_map, unit_cell, beam_radius=0.8, node_radius=None, curve_tolerance=0.05, member_blend_radius=0.0)[source]#

Tile a standard or custom graph (strut) cell through a CellMap.

One copy of the cell fills each map cell. Struts are curved to follow the map, and every radius is a physical length in millimetres.

Parameters:

  • cell_map (pv.CellMap | pv.CellMapCollection) – Map that places the cells, e.g. from rectangular_cell_map().

  • unit_cell (str | pv.GraphUnitCell | list) – A name from LATTICE_NAMES ("bcc", "octet", …), a pv.GraphUnitCell with vertices in [0, 1], or a list of edges ((x0, y0, z0), (x1, y1, z1)) in normalized cell coordinates spanning [-0.5, 0.5].

  • beam_radius (float | pv.FloatAttribute | callable) – Strut radius in mm, default 0.8. Must stay positive.

  • node_radius (float | pv.FloatAttribute | callable | None) – Radius in mm of a sphere added at every unit-cell vertex. None (default) adds no joint spheres.

  • curve_tolerance (float) – Largest chord error in mm allowed when a strut is subdivided to follow a curved map, default 0.05.

  • member_blend_radius (float | pv.FloatAttribute | pv.ScalarParameter | callable) – Radius in mm of the smooth blend that fillets the nodes where distinct struts and joints meet, default 0.0 (sharp). A field needs pv.ScalarParameter bounds. Struts shared by neighbouring cells count once, so they never bulge.

Controls accept a number, a pv.FloatAttribute field sampled at each point (plain x, y, z are in mm), or a Python function f(x, y, z, d) that is compiled with numba.cfunc.

Returns:

a pv.MappedGraphLattice for one map, or a pv.MappedStructureCollection when cell_map is a pv.CellMapCollection holding more than one map.

Return type:

pv.Node

Example

>>> node = mm.graph_lattice(cell_map, "bcc", beam_radius=1.0)

Any set of seeds inside one cell, repeated along U, V and W, divides space into Voronoi cells: the region closer to each seed than to any other. Each shared face is used once. Faces are repeated periodically and clipped to the cell, and polygons with more than four corners are triangulated. Every piece of one source face gets that face’s index as its face tag, and faces with the same plane direction share an orientation tag.

Parameters:

  • kinds (str | list[str] | None) – Only use faces of cells of these kinds.

  • face_tags (str | list | None) – Only use faces with these tags, for example "side" for a prism honeycomb’s walls.

Returns:

The wall cell, vertices in [0, 1].

Return type:

pv.FaceUnitCell

Example

>>> walls = mm.tessellation("triangular_prism").face_cell(face_tags="side")
>>> node = mm.face_lattice(cell_map, walls, wall_thickness=0.6)

Lattices from meshes#

pyvcad_metamaterials.mesh_lattice(mesh, rules='edges', beam_radius=0.5, node_radius=None, min_length=0.0)[source]#

Build a beam lattice from the cells of a volume or surface mesh.

The tessellation rules of GRAPH_RULES run on the mesh cells: "edges" keeps every mesh edge, "cell_vertex_centroid" joins each cell’s centre to its corners, "facet_vertex_centroid" joins each face’s centre to its corners, "dual" joins the centres of cells that share a face (on a triangle surface, a strut across every interior edge), and "central_axes" joins each cell’s centre to its face centres. Struts that neighbouring cells share are kept once. A list of rules gives their union.

Struts are centred on the mesh, so they bulge out of the part by their radius where they run along its surface; intersect the result with the part to trim them.

Parameters:

  • mesh (pv.TetrahedralMesh | pv.HexahedralMesh | pv.SurfaceMesh | tuple) – The cells. A (vertices, cells) tuple takes an (n, 3) array and cells of 3 (triangle), 4 (tetrahedron) or 8 (hexahedron, VTK order) vertex indices.

  • rules (str | list[str]) – One or more of GRAPH_RULES, default "edges".

  • beam_radius (float | array-like | pv.FloatAttribute | callable) – Strut radius in mm: a number, one value per mesh vertex (cell and face centres take the mean of their vertices), or a field sampled at both ends of every strut.

  • node_radius (float | array-like | pv.FloatAttribute | callable | None) – Radius in mm of a ball at every lattice vertex, given the same ways; None (default) adds none.

  • min_length (float) – Struts shorter than this (mm) are dropped, default 0.

Returns:

The lattice (new geometry; its distance is exact outside the struts and a bound inside, like any union of struts).

Return type:

pv.BeamLattice

Example

>>> settings = pv.TetrahedralMeshFixedSettings()
>>> settings.cell_size = 6.0
>>> tets = pv.TetrahedralMesh.from_tree(pv.Sphere(pv.Vec3(0, 0, 0), 20.0), settings)
>>> lattice = mm.mesh_lattice(tets, "edges", beam_radius=0.6)
